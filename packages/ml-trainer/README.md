# `modelscript-trainer` — Tier 2 GPU Dynamic-$m$ Relational Zonotope Training Kernels

`modelscript-trainer` implements formally sound, differentiable **Dynamic-$m$ Relational Zonotope** Transformer training kernels in PyTorch (+ optional Triton CUDA acceleration, with an automatic pure-NumPy autograd fallback for headless CPU environments without PyTorch).

## Architecture

- **`ZonotopeTensor`**: Elastic set representation $\mathcal{Z} = \langle c, G, e \rangle$ with center $c \in \mathbb{R}^{B \times L \times D}$, correlated relational generators $G \in \mathbb{R}^{B \times m \times L \times D}$, `group_ids`, and sound diagonal box slack $e \in \mathbb{R}_{\ge 0}^{B \times L \times D}$.
- **`RelationalZonotopeEmbedder`**: Maps 4-column compiled JSONL shards (`token_ids`, `group_ids`, `rel_type_ids`, `rel_signs`) emitted by `msx dataset compile` directly into `ZonotopeTensor`s.
- **`DynamicMLoraLinear`**: Frozen base weight $W_0$ + trainable low-rank LoRA adapters $B \cdot A$ with wrapping-free exact affine zonotope propagation (plus optional Triton fused CUDA kernel when Triton is installed).
- **`DynamicMRMSNorm`**: Formally sound zonotope RMSNorm using certified interval bounds on $\text{rms}(x)^{-1}$.
- **`DynamicMSelfAttention`**: Sound bilinear $QK^T$ (McCormick/centered Taylor), certified Taylor + exact interval Softmax linear relaxation, sound bilinear $PV$, and KV-cache prefix injection for retrieved DiskANN memory chunks.
- **`DynamicMSwiGLU`**: Sound SiLU linear relaxation with threshold-triggered selective generator expansion ($\text{gap} > \tau \Rightarrow m \to m + 1$) and sound bilinear $\text{SiLU}(\text{gate}) \odot \text{up}$.
- **`contract_generators`**: Vanishing-norm pruning ($\|g_k\| < \varepsilon_{\text{prune}}$), sound collinear merging ($|\cos(g_i, g_j)| \ge \theta$), and Girard `m_cap` VRAM-ceiling reduction emitting mechanistic interpretability events.
- **`QueryProjectionHead` & `DiskAnnMemoryClient`**: InfoNCE contrastive alignment for $q = \text{Normalize}(W_q h_t + b_q)$ and HTTP client for `POST /api/v1/memory/query`.
- **`DynamicMBucketSampler`**: `m_init`-bucketed shard loader minimizing generator-dimension padding across mini-batches.

## Slurm / `torchrun` Launch

Matches the exact CLI flags generated by `generatePyTorchSlurmRecipeExport` in `@modelscript/runtime`:

```bash
torchrun --nproc_per_node=4 -m modelscript_trainer.train_dynamic_m \
  --manifest training-recipe.manifest.json \
  --base-model "Qwen/Qwen2.5-Coder-1.5B" \
  --mode "posttrain-lora" \
  --lora-rank 16 \
  --m-start 1 \
  --m-max 24 \
  --m-cap 32 \
  --expansion-tau 0.05 \
  --prune-eps 0.0001 \
  --diskann-url "http://localhost:3001/api/v1/memory" \
  --output-dir checkpoints/msx_lora
```

Exports spec-compliant `adapter_model.safetensors`, `adapter_weights.json`, and a ModelScript `package.json` manifest with `modelscript.category = "lora-adapter"`.
