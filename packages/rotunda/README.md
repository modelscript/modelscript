# `@modelscript/rotunda`

WebXR Engineering Rotunda, 3D spatial diagram editor, drafting podium, and component showcase for ModelScript.

## Overview

This package provides the host-agnostic 3D/WebXR Engineering Rotunda workstation, spatial diagram stage, magnetic port wiring, drafting podium, turntable showcase carousel, matrix stockroom, wrist palette, multiplayer presence, and curated component gallery catalog used by `@modelscript/editor`, `@modelscript/ide-client`, and `@modelscript/web`.
