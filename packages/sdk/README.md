# `@modelscript/sdk`

TypeScript and AssemblyScript SDK for authoring user-defined ModelScript capabilities, visual artifacts, and WASM kernels.

## Installation & Build

```bash
npm run build --workspace=@modelscript/sdk
npm run typecheck --workspace=@modelscript/sdk
npm run test --workspace=@modelscript/sdk
```
