# `@modelscript/cad-viewer`

3D CAD, CAE (FEA/CFD), WebXR, and Zonotope viewport components for ModelScript.

## Overview

This package provides host-agnostic Three.js / React Three Fiber 3D rendering, CAD annotation parsing, CAE simulation tree & local browser FEA/CFD runner, VTK field visualization, WebXR session utilities, and shared-scissor 3D viewport hosting used by `@modelscript/editor`, `@modelscript/ide-client`, and `@modelscript/web`.
