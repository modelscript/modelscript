# `@modelscript/ide-packager`

VS Code extension packager, workspace language discovery, manifest generator, and esbuild bundler for ModelScript.

## Overview

This package discovers polyglot language packages across the ModelScript workspace, normalizes language descriptors and maturity tiers, generates VS Code `package.json` manifests, TextMate grammars, language configurations, and file icon themes, and bundles browser/desktop extension hosts, webviews, declarative DSL UI panels, and the browser LSP server with `esbuild`.
