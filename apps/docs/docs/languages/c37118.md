# IEEE C37.118 Synchrophasor / PMU Profiles (`.c37118`, `.pmu`)

The `@modelscript/c37118` package (`languages/c37118`) provides native support for **IEEE C37.118** synchrophasor and Phasor Measurement Unit (PMU) configuration profiles (`.c37118`, `.pmu`). It enables wide-area monitoring system (WAMS) telemetry validation, DAE measurement-channel lowering, and polyglot synchronization with power grid models.

---

## Supported File Formats

| Extension | Format                     | Description                                                                                    |
| :-------- | :------------------------- | :--------------------------------------------------------------------------------------------- |
| `.c37118` | IEEE C37.118 Configuration | PMU station metadata, `IDCODE`, reporting data rate, phasor/analog/digital channel definitions |
| `.pmu`    | PMU Profile                | Synchrophasor stream configuration and nominal frequency/scaling parameters                    |

---

## Capabilities

- **PMU Configuration Parser (`parseC37118`)**: Parses PMU station identifiers, nominal frequency (50/60 Hz), reporting frame rates, phasor channel descriptors (voltage/current, polar/rectangular), analog channels, and digital status words.
- **Static Diagnostics (`lintC37118Config`)**: Validates station configuration consistency, channel bounds, and reporting rate compliance (`C37_3001`, `C37_3002`, and structural checks).
- **DAE Arena Lowering (`lowerC37118ToDae`)**: Lowers PMU phasor magnitude, angle, frequency, and ROCOF measurement channels into `DAEBuilder` variables for co-simulation and digital twin state estimation.
- **LSP & Workspace Indexing (`indexC37118Document`, `getC37118DocumentSymbols`, `getC37118Diagnostics`)**: Provides document symbols, diagnostics, and workspace-wide indexing.
- **TGG Synchronization (`createC37118TggTransformer`)**: Links PMU channels bidirectionally to power system bus measurements and SysML v2 monitoring requirements.

---

## Programmatic TypeScript API

```typescript
import { lintC37118Config, lowerC37118ToDae, parseC37118 } from "@modelscript/c37118";

const config = parseC37118(sourceText);
const diagnostics = lintC37118Config(config);
const dae = lowerC37118ToDae(config);
```
