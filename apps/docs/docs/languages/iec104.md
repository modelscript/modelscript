# IEC 60870-5-104 Telecontrol Profiles (`.iec104`, `.104`)

The `@modelscript/iec104` package (`languages/iec104`) provides native support for **IEC 60870-5-104** substation telecontrol and SCADA station profiles (`.iec104`, `.104`). It parses ASDU/IOA point maps, validates protocol timing and address ranges, lowers SCADA telemetry points into `DAEBuilder`, and links telecontrol signals to physical grid models via TGG rules.

---

## Supported File Formats

| Extension | Format                  | Description                                                                                         |
| :-------- | :---------------------- | :-------------------------------------------------------------------------------------------------- |
| `.iec104` | IEC 60870-5-104 Profile | Station common address, TCP transport timing parameters (`t0`–`t3`, `k`, `w`), and IOA point tables |
| `.104`    | IEC 104 Station File    | Compact substation telecontrol configuration and ASDU type ID mappings                              |

---

## Capabilities

- **Station Profile Parser (`parseIec104`)**: Parses IEC 60870-5-104 station profiles, common ASDU addresses, Information Object Addresses (IOAs), data type IDs (single/double point, measured normalized/scaled/short-float), and control commands.
- **Static Diagnostics (`lintIec104Profile`)**: Validates protocol parameters (`IEC104_1001`–`IEC104_1003`), duplicate or invalid IOA definitions (`IEC104_2001`, `IEC104_2002`), and ASDU/command consistency (`IEC104_3001`, `IEC104_3002`).
- **DAE Arena Lowering (`lowerIec104ToDae`)**: Lowers SCADA analog measurements and binary status/command points into linear-memory `DAEBuilder` variables for hardware-in-the-loop and digital twin co-simulation.
- **LSP, Indexing & TGG (`indexIec104Document`, `getIec104DocumentSymbols`, `createIec104TggTransformer`)**: Provides workspace indexing, document symbols, diagnostics, and bidirectional TGG synchronization.

---

## Programmatic TypeScript API

```typescript
import { lintIec104Profile, lowerIec104ToDae, parseIec104 } from "@modelscript/iec104";

const profile = parseIec104(sourceText);
const diagnostics = lintIec104Profile(profile);
const dae = lowerIec104ToDae(profile);
```
