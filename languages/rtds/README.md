# @modelscript/rtds

RTDS RSCAD Draft (`.dft`) real-time digital simulator & Hardware-in-the-Loop (HIL) netlist compiler, EMT time-step validator, ATP-EMTP projector, LSP services, and linear-memory `DAEBuilder` lowering for ModelScript.

## Usage

```bash
npm run build --workspace=@modelscript/rtds
npm test --workspace=@modelscript/rtds
```
