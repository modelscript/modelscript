# @modelscript/cyme

Eaton CYME (`CYMDIST` `.sxst` XML & ASCII) distribution feeder compiler, semantic linter, OpenDSS `.dss` projector, LSP services, and linear-memory `DAEBuilder` lowering for ModelScript.

## Usage

```bash
npm run build --workspace=@modelscript/cyme
npm test --workspace=@modelscript/cyme
```
