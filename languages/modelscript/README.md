# @modelscript/modelscript

Native ModelScript (`.msx`, `.modelscript`, alias `@modelscript/lang`) systems programming and polyglot query language compiler. Combines low-level `@unmanaged struct` WebAssembly linear memory layouts, XQuery-style FLWOR relational queries, Salsa type/layout inference, static linting (`MSX1001`–`MSX5002`), and multi-target code generation (JavaScript, WebAssembly binary/WAT, and native C/binary).

---

## Core Capabilities

- **WASM GLR Incremental Parser**: Generated by `@modelscript/dsl` (`buildParser`) into native WebAssembly (`parser.wasm`) supporting `.msx` and `.modelscript` files with incremental error recovery and GLR conflict resolution.
- **`@unmanaged struct` Zero-Copy Linear Memory Layouts**: Declares C/WASM-compatible value-type structures (`@unmanaged struct`) with hardware scalar primitives (`i32`, `u32`, `i64`, `u64`, `f32`, `f64`, `bool`, `string`, `usize`, `void`) and generic containers (`Array<T>`, `Slice<T>`, `ptr<T>`), computing exact field byte offsets, natural alignment padding, and structure tail padding for zero-copy WebAssembly arena interop.
- **XQuery-Style FLWOR Relational Queries**: Native `for ... in ... let ... := ... where ... order by ... ascending|descending return ...` comprehension expressions for declarative querying, filtering, and sorting across in-memory collections and polyglot engineering models.
- **Multi-Target Code Generation (`ModelScriptCompiler`)**:
  - **`JsEmitter`**: Compiles ModelScript ASTs into executable JavaScript modules (`compileToJs`, `executeJs`).
  - **`WasmEmitter`**: Lowers functions, `@unmanaged struct` memory accesses, control flow, and arithmetic directly into WebAssembly Text Format (`compileToWat`) and binary `.wasm` modules (`compileToWasm`, `executeWasm`).
  - **`NativeEmitter`**: Compiles ModelScript programs into native C source and standalone machine binaries via system toolchains (`compileToNative`).
- **Salsa `ModelScriptQueryEngine`**: Revision-tracked memoized query engine computing `structLayout` (field offsets, alignments, total byte size) and `inferExpressionType` across expressions, binary operators, array literals, and FLWOR return clauses.
- **10 `MSX1001`–`MSX5002` Compiler Lint Rules (`ModelScriptLinter`)**: Static scope, type-checking, FLWOR binding, function arity, and struct field verification diagnostics.
- **Bidirectional Polyglot TGG Rules**: Synchronizes ModelScript structs and parameter declarations with Modelica `record` definitions and component modifications, alongside built-in primitive type maps for Modelica and SysML v2 (`KerML` / `ISQ`).

## Package Structure

| Path                            | Description                                                                                                               |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `src/index.ts`                  | `ModelScriptCompiler` facade (`init`, `parse`, `lint`, `compileToJs`, `compileToWat`, `compileToWasm`, `compileToNative`) |
| `src/language.ts`               | `modelscriptLanguage` grammar specification, FLWOR rules, LSP action (`run_modelscript`), and polyglot TGG rules          |
| `src/queries.ts`                | `ModelScriptQueryEngine` memoized Salsa queries (`structLayout`, `inferExpressionType`, `getTypeSizeAndAlign`)            |
| `src/linter.ts`                 | `ModelScriptLinter` CST static analysis and type checker                                                                  |
| `src/errors.ts`                 | `ModelScriptErrorCode` diagnostic registry (`MSX1001`–`MSX5002`)                                                          |
| `src/codegen/js-emitter.ts`     | `JsEmitter` lowering CST nodes (including FLWOR queries and structs) to JavaScript                                        |
| `src/codegen/wasm-emitter.ts`   | `WasmEmitter` lowering CST nodes to WebAssembly Text (`.wat`) and binary `.wasm`                                          |
| `src/codegen/native-emitter.ts` | `NativeEmitter` lowering CST nodes to C99 and native machine executables                                                  |

## Compiler Lint Rules (`MSX1001`–`MSX5002`)

| Code      | Rule                      | Severity | Description                                                                                   |
| --------- | ------------------------- | -------- | --------------------------------------------------------------------------------------------- |
| `MSX1001` | `parse-error`             | `error`  | Syntax error detected by the native WebAssembly GLR parser                                    |
| `MSX2001` | `undefined-variable`      | `error`  | Variable `'name'` is not declared in the current lexical scope                                |
| `MSX2002` | `duplicate-declaration`   | `error`  | Identifier `'name'` is already declared in the current scope                                  |
| `MSX2003` | `unknown-type`            | `error`  | Type `'typeName'` is not a recognized primitive, generic (`Array`, `Slice`, `ptr`), or struct |
| `MSX3001` | `type-mismatch`           | `error`  | Cannot assign value of `'sourceType'` to target of `'targetType'`                             |
| `MSX3002` | `invalid-binary-operand`  | `error`  | Binary operator `'op'` cannot be applied to operands of type `'type'`                         |
| `MSX4001` | `non-iterable-collection` | `error`  | Expression in FLWOR `for` clause does not evaluate to an iterable collection                  |
| `MSX4002` | `flwor-unbound-variable`  | `error`  | Variable referenced in FLWOR clause is not bound in preceding `for` or `let` clauses          |
| `MSX5001` | `argument-count-mismatch` | `error`  | Function call argument count does not match the function declaration signature                |
| `MSX5002` | `unknown-struct-field`    | `error`  | Accessed field does not exist on the target `struct` declaration                              |

## Programmatic Usage

```typescript
import { ModelScriptCompiler } from "@modelscript/modelscript";

const compiler = new ModelScriptCompiler();
await compiler.init();

const source = `
@unmanaged struct SensorSample {
  id: i32;
  voltage: f64;
  valid: bool;
}

let readings = [11.8, 12.4, 14.2, 12.1];
let highVoltages =
  for v in readings
  let scaled := v * 1.05
  where scaled > 12.5
  order by scaled descending
  return scaled;
return highVoltages;
`;

// 1. Lint & inspect @unmanaged struct linear memory layout
const diagnostics = compiler.lint(source);
const tree = compiler.parse(source);
const layout = compiler.queries.structLayout(tree.rootNode.namedChildren[0]);
console.log(layout.totalSize, layout.alignment, layout.fields);

// 2. Execute via JS backend or compile to WebAssembly
const result = compiler.executeJs(source);
const wasmBytes = await compiler.compileToWasm(`
  function add(a: i32, b: i32): i32 {
    return a + b;
  }
`);
```
